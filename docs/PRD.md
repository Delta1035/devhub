# DevHub 产品需求

## 背景与问题

个人维护多个项目，目前每个项目都要开一个 VSCode / IDEA 实例再执行启动脚本：

- 多个 IDE 实例严重消耗机器资源，而实际同一时间只专注开发一个项目；
- 对接不同后端时需要切换各应用的启动脚本或配置，繁琐易错。

## 目标

一个轻量桌面客户端，统一管理所有本地项目的脚本运行，让 IDE 只为正在开发的项目打开。

## 用户

开发者本人（单用户、本机使用）；后续通过 Android 远程查看与控制。

## 功能范围

### M1 — 能跑起来

- 添加/移除项目目录
- 自动识别脚本：npm/pnpm/yarn scripts、Maven、Gradle
- 启动、停止、重启脚本；停止时杀掉整棵进程树（Windows/Linux）
- 实时日志（保留 ANSI 颜色），保留最近 N 行
- 关闭窗口最小化到托盘，进程继续运行

### M2 — 切换后端

- 项目内可选的 `.devhub.yaml`：自定义脚本、Profile
- Profile：环境变量、追加参数；一键切换并重启
- 启动前端口冲突检测

### M3 — 编排

- 分组：一组脚本按顺序一起启动
- 健康检查（端口/HTTP）
- 运行历史

### M4 — 远程

- 可选开启的 HTTP + WebSocket API（Token 鉴权，默认关闭，推荐经 Tailscale 访问）
- 适配手机的 Web 界面 / PWA；之后 React Native (Expo) Android 客户端

## 非目标

- 不做代码编辑、不替代 IDE
- 不做多用户、团队协作
- 暂不支持 macOS
