# DevHub 产品需求

## 背景与问题

个人维护多个项目，目前每个项目都要开一个 VSCode / IDEA 实例再执行启动脚本：

- 多个 IDE 实例严重消耗机器资源，而实际同一时间只专注开发一个项目；
- 多个项目的服务要按顺序逐个启动，繁琐易错。

## 目标

一个轻量桌面客户端，统一管理所有本地项目的脚本运行，让 IDE 只为正在开发的项目打开。

## 用户

开发者本人（单用户、本机使用）；后续通过 Android 远程查看与控制。

## 功能范围

桌面 MVP 包含下列 M1～M3 已实现的本地功能，并完成运行历史完善；发布前继续验证 Windows 自动升级与 Linux AppImage 更新。CLI 与手机端远程管理暂缓，不纳入当前 MVP（2026-10-03 用户确认）。

### M1 — 能跑起来

- 添加/移除项目目录
- 自动识别脚本：npm/pnpm/yarn scripts、Maven、Gradle
- 启动、停止、重启脚本；停止时杀掉整棵进程树（Windows/Linux）
- 实时日志（保留 ANSI 颜色），保留最近 N 行
- 关闭窗口最小化到托盘，进程继续运行

### M2 — 项目配置

- 项目内可选的 `.devhub.yaml`：自定义脚本
- 启动前端口冲突检测

### M3 — 编排

- 分组：一组脚本按顺序一起启动
- 健康检查（端口/HTTP）
- 运行历史
- 异常中断恢复、历史清理与每次运行的有限日志保存（最近 512 KB，每脚本最近 20 次）

### M4 — 远程

- 可选开启的 HTTP API + SSE 事件推送（Token 鉴权，默认关闭，推荐经 Tailscale 访问；ADR 0022）
- 适配手机的 Web 界面 / PWA；之后用 Capacitor 打包同一网页为 Android 客户端（ADR 0027），以后再考虑 React Native (Expo) 原生客户端

## 非目标

- 不做代码编辑、不替代 IDE
- 不做多用户、团队协作
- 暂不支持 macOS
