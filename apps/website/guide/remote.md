# 手机访问

开启远程访问后，可以在手机浏览器中查看项目、启动 / 停止脚本和查看日志。手机打开的是 DevHub 自带的网页版，由桌面端直接提供，不需要另外部署。

推荐配合 [Tailscale](https://tailscale.com/) 使用：手机与电脑登录同一个 tailnet，流量经 WireGuard 加密，在外网也能连接。

## 扫码连接

1. 在电脑上打开「设置 → 远程访问」，开启「允许手机远程访问」。
2. 「监听地址」选择标有「推荐」的 Tailscale 地址（`100.x.y.z`）。
3. 点击「显示二维码」，用手机扫码。浏览器会打开 DevHub 并自动连接；令牌保存在手机浏览器中，之后直接打开同一地址即可。

二维码中包含访问令牌，不要截图或给他人看。怀疑泄露时点「重新生成…」，已连接的设备会立即断开。

## 安装到主屏幕（HTTPS）

浏览器只允许在 HTTPS 页面上「添加到主屏幕 / 安装应用」。DevHub 本身不提供 HTTPS，由 Tailscale 代为提供：

1. 在 Tailscale 管理后台的 DNS 页面开启 MagicDNS 和 HTTPS 证书。
2. DevHub 的「监听地址」改为 `127.0.0.1`。
3. 在电脑上运行（端口与设置中一致）：

   ```sh
   tailscale serve --bg 7420
   ```

   命令会输出访问地址，形如 `https://本机名.你的-tailnet.ts.net/`。

4. 用手机浏览器打开这个地址，粘贴访问令牌（在电脑上的「访问令牌」处复制）。也可以直接打开 `https://本机名.你的-tailnet.ts.net/#token=令牌`，令牌读入后会从地址栏清除。
5. 在 Chrome 菜单中选择「添加到主屏幕」或「安装应用」。

停止对外提供：`tailscale serve --https=443 off`。查看当前配置：`tailscale serve status`。

`tailscale serve` 只对你的 tailnet 内的设备开放，不会暴露到公网（那是 `tailscale funnel`，不要使用）。

## Android App

不想用浏览器时，可以安装 Android App。它和网页版界面相同，但不需要 HTTPS，访问令牌加密保存在系统密钥库（Android Keystore）中。

1. 从 [Releases](https://github.com/Delta1035/devhub/releases) 下载 `DevHub-版本号.apk`，在手机上打开安装（需允许「安装未知应用」）。App 与桌面端版本号一致，建议安装相同版本。
2. 在电脑上开启远程访问（同上），记下「监听地址」与端口。
3. 打开 App，在「桌面端地址」填 `地址:端口`（如 `100.64.1.2:7420`），在「访问令牌」粘贴电脑上复制的令牌，点「连接」。更简单的做法：在电脑上点「复制连接地址」，把它粘贴到「桌面端地址」，令牌会自动读出。

之后打开 App 会自动连接。桌面端升级后，App 会自动下载与桌面端同版本的界面，提示「重启后生效」；需要新版 App 时会提示下载。令牌被重新生成后，App 会回到连接页，重新填写令牌即可；要连接另一台电脑，在连接失败的页面点「更换桌面端」。

## 手机上能做什么

- 查看项目、脚本、批量任务和运行历史，启动 / 停止 / 重启脚本，执行批量任务。
- 查看终端输出。「远程终端」默认不允许：手机不能新建终端，也不能向终端输入；允许后手机可以在这台电脑上执行任意命令，请谨慎开启。
- 添加 / 移除项目、修改 DevHub 设置、用编辑器打开项目等会改变电脑上内容的操作只能在电脑上进行。

## 常见问题

- **扫码后打不开**：确认手机已连上 Tailscale，且监听地址不是 `127.0.0.1`（使用 `tailscale serve` 时除外）。
- **显示「访问令牌无效或已重新生成」**：电脑上重新生成过令牌，粘贴新令牌即可。
- **局域网直连**：监听地址也可以选局域网地址或「所有地址」，但这时是明文 HTTP，同一网络中的设备可能看到令牌和日志。
